# 先锋语音保留音源测试清单

导航、提示音及 Siri 输出首次申请焦点和音频数据间隔超过 500 毫秒后恢复时，不再主动选择媒体音源 300。400 混音通道及独立焦点保持原样；媒体、通话及麦克风授权的音源策略保持原样。

## 实车测试

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 音乐暂停 | 播放后暂停，连续触发至少三次导航播报 | 导航清晰出声，音乐一直暂停 |
| 播客暂停 | 播放后暂停，连续触发至少三次导航播报 | 导航清晰出声，播客进度不继续 |
| 音源为 OFF | 暂停后确认车机退出 300，再触发导航 | 导航有声，音源不因导航变为 300，无自动 PLAY |
| FM | FM 播放中触发导航 | 保持 FM 音源，导航混音可闻，结束后 FM 正常 |
| 蓝牙音乐 | 蓝牙音源播放中触发导航（具备同时连接条件） | 保持蓝牙音源，导航可闻，不启动 CarPlay 媒体 |
| CarPlay 正在播放 | 音乐和播客分别播放中触发导航 | 媒体和导航正常，播报结束音量正常 |
| 连续与间歇播报 | 短间隔、超过 500 毫秒及长间隔后分别播报 | 每段都有声音，均不因播报切换音源 |
| 首次声音 | 重连后不播放媒体，首先触发导航 | 第一段导航可闻，无媒体自启 |
| 提示音 | 在媒体暂停及 FM 下触发 CarPlay 提示音 | 提示音正常，不切音源、不自启媒体 |
| Siri 输出 | FM/媒体暂停时触发 Siri 回复或语音播报 | 输出混音正常；区分麦克风授权引发的音源切换 |
| Siri 完整交互 | 唤醒、说话、听回复、退出，分别覆盖 FM 和暂停状态 | 收音和回复正常，记录是否触发自动 PLAY |
| 用户主动播放 | 导航播报期间点击播放或方向盘播放键 | 正常播放，不被拦截 |
| 通话 | 来电接听、去电、挂断后再导航，覆盖暂停和播放状态 | 双向通话正常，导航正常，无新增自动播放 |
| 媒体音源恢复 | FM 切回 CarPlay 并主动播放；暂停/重播 | 仍可正常选择 300 和输出媒体 |
| 重连 | 有线/无线分别断开重连，重复暂停后导航 | 行为一致，无残留状态 |

## 日志核对

- 导航/助手输出应出现 `Audio: preserving Pioneer source channel=... streamType=400`。
- 单纯导航触发不应出现 `Pioneer media source previous=... requested=300` 或随后的非用户 `media command=1`。
- 对照播报前后的 `phonePlaying`、音源和实际听感；媒体暂停时应持续为 false。
- Siri 麦克风仍使用原有授权流程，其中会选择 300。本次不承诺完整 Siri 交互不切音源；若出现自动播放，应单独记录麦克风日志，后续针对授权流程验证修改，避免影响通话收音。

本地单元测试只能验证选择音源及焦点调用策略，不能证明先锋固件允许跨音源出声，必须完成上述实车验收。
