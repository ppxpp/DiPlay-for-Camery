# 车机开机启动助手

存放用于车机开机后拉起 DiPlay 的配套 Android 应用，由项目使用者提供原始 APK。

| 安装包 | 版本说明 |
| --- | --- |
| [开机启动（A）替换车机微信_开关版.apk](开机启动（A）替换车机微信_开关版.apk) | 带开关的版本 |

## 包信息与使用范围

- 应用名称：盒子助手。
- 包名：`com.tencent.mm`，用于替换车机微信对应的应用入口。
- 版本号为 `1.0`，versionCode 为 `1`，最低系统版本为 Android 7.1（API 25）。
- 内部目标包名为 `com.gtmc.app.fengyunyx.b819`，与当前分支的 DiPlay mobile 应用一致。
- 开机拉起效果取决于车机固件对该应用入口的启动行为；当前仅核对 APK 包信息、目标包名与文件完整性，尚未验证该 APK 的实车开机行为。
- 本目录保存独立安装包，DiPlay 构建不会将它嵌入主应用。
