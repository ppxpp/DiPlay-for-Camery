# DiPlay

## 凯美瑞车机适配版（本仓库重点）

> **本仓库面向丰田凯美瑞先锋车机，提供与原车操作相结合的 CarPlay 体验。** 基于 DiPlay，针对车机连接、声音通道、方向盘按键和日夜模式进行适配，并与原车爱趣听（WeCarFlow）协同工作。

应用名为 **DiPlay-凯美瑞A导航**，包名为 `com.gtmc.app.fengyunyx.b819`，基于上游 **v0.2.21**。通过原车按键控制音乐、跟随车机切换白天和黑夜，并在使用 CarPlay 时协调爱趣听的播放行为，减少两个应用争抢声音的情况。

### 凯美瑞适配功能

| 适配内容 | 使用说明 |
| --- | --- |
| 先锋车机连接 | 针对先锋固件处理有线连接与数据传输，支持连接超时处理和重试。 |
| 原车声音通道 | 对接车机音源管理，分别处理 CarPlay 音乐与导航提示的播放通道。 |
| 方向盘按键 | 通过 WeCarFlow 桥接，将原车前后曲按键交给 CarPlay 使用。 |
| 爱趣听播放保护 | DiPlay 启动时只拉起所需桥接服务，不启动爱趣听的播放器业务；CarPlay 连接后启用相应的播放冲突保护。 |
| 音乐使用提醒 | 保护生效时，打开爱趣听会提示优先使用 CarPlay 音乐。提示支持关闭，也可勾选“本次不再提示”。 |
| 白天／黑夜同步 | CarPlay 跟随原车昼夜状态切换，配合车机的日间与夜间使用场景。 |

### DiPlay 与爱趣听怎样配合

**DiPlay** 负责连接 iPhone、显示 CarPlay、播放声音和接收触控；**WeCarFlow 桥接**负责对接原车按键、播放状态和冲突保护。使用 CarPlay 音乐时，建议通过 CarPlay 选择和播放歌曲，避免同时在爱趣听中播放音乐。

**关闭提醒窗口不会解除播放保护。** 勾选“本次不再提示”后，爱趣听主进程重启前不再弹出；只退到后台或断开后重新连接 CarPlay，不会清除这项选择。

本分支最低支持 Android 6.0（API23），DiPlay 与配套 WeCarFlow 使用共用签名。适配范围为凯美瑞先锋车机，具体兼容性取决于车型、车机固件和 iPhone 系统版本。配套项目说明见 [WeCarFlow](wecarflow/README.md)。

## 0.2.21 — 公开预览版

本适配分支 APK 的最低版本为 Android 6.0（API23），请安装在允许 APK 安装的车机上；具体兼容性取决于车机固件与 iPhone 系统版本。无需越狱、转接盒、账户或认证服务器。有线及无线核心连接不要求 ADB；可选车辆数据及车辆控制需要支持的固件和已授权网络 ADB。

Wi-Fi Direct 现支持 Android 7.0–9 的旧版建组路径，使用系统返回的真实凭据。首选信道依赖固件 API；Android 7.0–9 无法读回协商频率，所以请求信道在诊断中标为未经验证，系统默认为信道 0。Android 10+ 保留频率验证。也可使用车机内置热点、USB 或[现有 Wi-Fi／同一局域网](docs/EXISTING_WIFI.md)；同一局域网模式由车机和 iPhone 自行连接外部路由器，DiPlay 不替你修改默认路由。[Android 9 Wi-Fi Direct 限制](docs/ANDROID9_WIFI_DIRECT.md)说明清理及持久配置边界。

### 新增与修正

- **音乐**：修正 0.2.20 中音乐落后于 iPhone 的问题；暂停、切歌不再延迟几秒，播放速度也不再忽快忽慢。
- **有线连接**：iPhone 收下开始请求却一直不打开 CarPlay 时，DiPlay 会自动重新连接；点“断开连接”后不再一直等待；已经自行恢复的连接不再被重试断开。
- **麦克风与音乐**：在没有安卓自带 Opus 编码器的车机上使用麦克风时，DiPlay 不再闪退；通话或短暂打断后，音乐会恢复播放。
- **无线连接与比亚迪车机**：无线 CarPlay 无法启动时会显示原因；CarPlay 结束后，DiPlay 会把仪表交还给原车；从 DiYou 桌面卡片打开时不再闪退；Android 10 以上的比亚迪车机可使用“隐藏比亚迪来电弹窗（实验性）”。
- **安装与语言**：DiPlay 可安装在 Android 7.0 上，并新增意大利语。
- **新选项（默认关闭）**：临时显示系统栏（5 秒）、黑色圆角遮罩、方向盘播放／暂停按钮、双击触发 Siri、导入车机热点详情（实验性）、桌面悬浮球（实验性）、车辆原厂音乐律动。
